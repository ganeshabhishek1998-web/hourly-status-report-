# Hourly Status Report — Android

Native Android app starter using Kotlin + Jetpack Compose.

## Open in Android Studio

Open the repository, then choose the `android` folder as the Gradle project.

## Build

Use Android Studio's Gradle sync and Build > Make Project.

The app currently provides:
- Hourly Status Report dashboard
- Existing sample entries
- Add Current Hour action
- Mobile-first Compose UI

The existing web application remains in the repository root.
